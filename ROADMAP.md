# ROADMAP

Текущая версия — **0.9.4**.

## 0.9.4 — сделано

- Установка напрямую из GitHub:
  `github:kachanov-e-v/dsh-chat-model#v0.9.4`.
- README и релизный тег `v0.9.4`.

## Ближайшие улучшения

1. **Стриминг частичного ответа из DOM в DSH.** Показывать текст по мере
   появления, а не ждать полный round-trip.
2. **Самовосстановление селекторов DeepSeek.** Эвристический поиск composer и
   ответа при изменении вёрстки, понятная ошибка вместо `NO_INPUT`.
3. **Официальный DeepSeek API как fallback.** Нативные tool-calls, контекст и
   стриминг без DOM — для больших проектов и низкой задержки.
4. **Живые smoke-тесты.** Новый чат, `CONTEXT_LIMIT`, восстановление после
   `EMPTY`, выбор модели в конкретной сессии.
5. **Резервный выбор модели через клиентский model selector**, если
   `sessionController` недоступен в профиле.

## 0.9.3 — сделано

- При `CONTEXT_LIMIT` плагин сам создаёт новый чат и повторяет запрос с полным
  промптом; отдельный cooldown 60 секунд.
- Полный промпт уменьшен до **60 000** символов, память — до 6 000,
  tool-результаты — до 10 000.
- Инкрементальные продолжения сохранены.
- Авто-новый чат не срабатывает по размеру промпта или неразобранному ответу.

## 0.9.2 — сделано

- Инкрементальные промпты: полный первый запрос, затем только новые сообщения.
- Детект «Length limit reached / Please start a new chat».
- Компактификация истории и ограничение полного промпта.

## 0.9.0 — сделано

- `PROJECT_MEMORY.md`: автоматическое создание, загрузка и обновление моделью.
- Включение по сессиям сохраняется в `sessions.json`.
- Компактификация контекста.
- Авто-новый чат только при `EMPTY`/`NO_ANSWER` с cooldown.

## 0.8.0 — сделано

- Только DeepSeek: один браузерный провайдер и модель `DeepSeek (browser)`.
- Включение по чату через `sessionController.selectModel`; `NOT_ENABLED` в
  других чатах.
- Зелёный чип, панель рядом с чипом, закрытие по клику вне окна.
- Разбор `<tool_call>` в code fence и DSML.

## Известные ограничения

- Каждый шаг — браузерный round-trip; ответы медленнее API.
- Вёрстка DeepSeek может измениться.
- Контекст веб-чата ограничен; очень большие проекты требуют компактификации
  или API.
- Автоматизация потребительского веб-чата может нарушать условия DeepSeek.
